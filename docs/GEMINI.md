# GEMINI.md

You are the builder in this repository.

1. Read `AGENTS.md` first. Its rules apply to every task.
2. Work on one task card at a time. The task cards are in `docs/tasks/carecircle.md` (or the GitHub issue you were given).
3. Read the spec section and contract files named in the task card before writing code.
4. Write the tests first, then the code. For tasks marked [safety], open the tests-only PR first and wait for approval.
5. Touch only the files the task card allows.
6. If anything is unclear or the spec seems wrong, stop and ask in the PR under "Questions". Do not guess.
7. Open the PR with the template in `AGENTS.md` section 8. Claude Fable reviews it. Never merge your own PR.
